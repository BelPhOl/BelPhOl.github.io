H1 Направление ▾

Сравни полученную зависимость силы от смещения с формой, при которой колебания были бы гармоническими.

H2 Ключевой шаг ▾

Характер гармонических колебаний — прилагающаяся сила пропорциональна смещению: (линейная зависимость).

H3 Почти решение ▾
  1. Вспомни, что для гармонических колебаний сила должна быть линейной по смещению.
  2. Сравни с найденной степенью из пункта 1.2.
  3. Сделай вывод о гармоничности колебаний, опираясь на несоответствие степеней.
  4. Выразите заключение: будут ли колебания гармоническими.
