1.1.1
H1 Направление ▾

Найди на снимке, в какую сторону смещаются последовательно отмеченные позиции стержня — последовательность кадров показывает движение.

H2 Ключевой шаг ▾

Каждая яркая полоска соответствует положению стержня в отдельный момент времени при прохождении каретки; сравнивай их расположение по сетке.

H3 Почти решение ▾
  1. Разметь на рисунке координатную сетку и подпиши подряд номера моментов времени для видимых полосок.
  2. Измерь смещения полосок в клетках вдоль направления скатывания для последовательных моментов.
  3. Проследи возрастание или убывание координат с временем и однозначно определи направление смещения.
  4. Выразите направление движения стержня из полученной последовательности измерений.

H1 Направление ▾

Обрати внимание на то, как меняются интервалы между положениями стержня: расстояния между соседними метками растут с временем.

1.3.1
H1 Направление ▾

На снимке есть почти вертикальная линия, для которой изображения стержня пересекаются — это связано с осью вращения, остающейся неподвижной в проекции.

H2 Ключевой шаг ▾

Ось вращения проецируется как набор точек, положение которых не меняется при оборотах; пересечения изображений через равные промежутки времени соответствуют положениям через половину оборота.

H3 Почти решение ▾
  1. Найди на рисунке точки пересечения следующих изображений стержня и нанеси их на одну координатную линию.
  2. Проведи через эти точки прямую — она даёт графическое положение оси вращения .
  3. Определи направление вращения, проследив смещение концов стержня с ростом времени (влево или вправо относительно оси).
  4. Выразите координаты положения оси из полученной совокупности пересечений.
