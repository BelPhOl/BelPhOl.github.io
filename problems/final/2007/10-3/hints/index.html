H1 Направление ▾

Нарисуй параллелепипед через мембрану и подумай, какие величины меняются при переносе частиц. Как связаны изменения числа частиц в наружном и внутреннем слоях с потоками через мембрану?

H2 Ключевой шаг ▾

Запиши уравнения баланса числа частиц для двух слоёв (учти диффузионный поток и при необходимости поток от насосов) и используй выражения для суммарного потока в видах и . Для поля внутри мембраны используй выражение напряжённости для плоских слоёв (метод Гаусса).

H3 Почти решение ▾
  1. Выдели объём с единичной площадью и выпиши уравнения изменения чисел частиц в наружном и внутреннем слоях, подставив потоки через мембрану.
  2. Перейди к уравнениям для концентраций, воспользуйся и выпиши уравнение для установившейся (стационарной) ситуации (временные производные равны нулю).
  3. Запиши условие сохранения общего числа частиц и выражение для разности потенциалов через (поле плоских слоёв). Подставь полученные выражения концентраций через в стационарные уравнения потоков.
  4. Получишь алгебраическую (квадратную) зависимость для ; вырази из полученной системы.
