Подсказки сгенерированы ИИ и не проверялись человеком — официальными они не являются.

1.1
H1 Направление ▾

Нарисуй графики зависимостей напряжения на переменном резисторе от его сопротивления для обоих диапазонов. Обрати внимание, являются ли эти зависимости линейными и как меняется ток при увеличении R.

H2 Ключевой шаг ▾

Модель приборной схемы — источник с ЭДС и внутренним сопротивлением, подключённый к внешнему резистору; для полной цепи применим закон Ома в общем виде (связь напряжения, тока, ЭДС и внутреннего сопротивления).

H3 Почти решение ▾
  1. Измерь и выпиши для ряда значений R соответствующие показания U.
  2. Вычисли для тех же точек силу тока в цепи через соотношение между U, R и током (получи набор пар (I,U)).
  3. Построй график U(I) и выполни аппроксимацию прямой вида, соответствующей уравнению линии нагрузки.
  4. Из полученной линейной зависимости вырази параметры источника — ЭДС ε и внутреннее сопротивление r из полученной системы.
2.1
H1 Направление ▾

Нарисуй схему с двумя омметрами и переменным резистором; обрати внимание, как меняются показания омметров при подключении второго прибора. Как изменится ток в общей цепи при добавлении второго омметра?

H2 Ключевой шаг ▾

Модель: каждый омметр заменяется источником ЭДС с внутренним сопротивлением; при измерении омметр отображает сопротивление внешней цепи, вычисляемое по измеренному напряжению и току. Запиши закон Ома для полной цепи и связь напряжения на внешнем резисторе с током для соответствующих случаев.

H3 Почти решение ▾
  1. Обозначь показания каждого омметра при отключенном другом как и , а при одновременном подключении — как и .
  2. Для каждого омметра при отдельном подключении выпиши уравнения вида и , где и — внутренние параметры конкретного омметра; свяжи эти уравнения с показаниями и .
  3. Для случая, когда оба омметра подключены одновременно, запиши уравнения тока и напряжения, учитывая, что омметры влияют друг на друга через общую цепь (токи складываются/перераспределяются согласно их внутренним сопротивлениям).
  4. Составь систему уравнений для неизвестных внутренних параметров омметров и внешнего сопротивления по полученным четырём показаниям и выразите внутренние сопротивления и ЭДС омметров из полученной системы.
3.1
H1 Направление ▾

Собери схему с диодом в прямом включении через известный последовательный резистор и снимай зависимость при плавном изменении напряжения на резисторе (или переменном R).

H2 Ключевой шаг ▾

Измеряй напряжение на диоде и на последовательном резисторе; силу тока через диод находи по закону Ома для последовательного резистора , затем построй вольтамперную характеристику .

H3 Почти решение ▾
  1. Собери схему: источник (омметр/переменный резистор), последовательный известный резистор и диод, измеряй и для серии положений переменного резистора.
  2. Для каждой точки вычисли ток через диод по измеренному падению на последовательном резисторе.
  3. Построй график зависимости тока от напряжения на диоде в выбранном диапазоне напряжений.
  4. Проанализируй форму полученной ВАХ и вырази зависимость через измеренные величины для дальнейшей интерпретации.
а)
H1 Направление ▾

Отключи один омметр и измерь показания другого при тех же значениях переменного резистора; зафиксируй результаты для последующего сравнения.

H2 Ключевой шаг ▾

Мультиметр в режиме омметра при отдельном подключении можно описать моделью с внутренней ЭДС и внутренним сопротивлением — эти параметры уже найдены в части 1 и пригодятся для расчёта.

H3 Почти решение ▾
  1. Для каждого значения резистора запиши показание омметра при отключённом другом приборе.
  2. Вычисли соответствующие токи и напряжения в цепи, используя найденные в части 1 параметры омметра, чтобы подготовить данные для сравнения с параллельным случаем.
  3. Сравни полученные отдельные показания с исходными измерениями из части 1, чтобы убедиться в согласованности данных.
  4. Подготовь таблицу отдельных показаний для последующего использования в теоретических расчётах.
б)
H1 Направление ▾

Подключи оба омметра параллельно (с одинаковой полярностью) и замерь их показания при тех же значениях резистора; запиши пары показаний для каждого значения.

H2 Ключевой шаг ▾

При параллельном подключении ток в узле распределяется между омметрами; используй модель двух источников с их внутренними сопротивлениями и расчётную схему параллельного соединения для предсказания показаний.

H3 Почти решение ▾
  1. Для каждого значения резистора измерь и занеси в таблицу показания обоих омметров в параллельном включении.
  2. Вычисли токи через каждый омметр и напряжение на резисторе, опираясь на модель из части 1.
  3. Сравни экспериментальные пары показаний с расчётными ожиданиями и отметь закономерности (увеличение/смещение показаний).
  4. Подготовь данные для формулировки уравнений, которые дадут теоретические значения tilde R_1 и tilde R_2.
