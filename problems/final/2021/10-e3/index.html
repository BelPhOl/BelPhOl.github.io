В этой части измерения проведите для обоих цилиндров.

3.1

3.1 Измерьте зависимость времени скатывания цилиндров (на всю длину желоба) от высоты подъема одного конца желоба .

3.2

3.2 Представьте полученные результаты графически в линеаризованном виде. Графики зависимостей для двух цилиндров приведите на одном бланке.

3.3

3.3 Качественно кратко (одним предложением) объясните возможные различия между результатами, полученными для разных цилиндров.

3.4 Рассчитайте значение параметра для сплошного цилиндра.
