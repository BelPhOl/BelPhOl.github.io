Подсказки

Открывайте по одной — попробуйте продвинуться после каждой, прежде чем открывать следующую.

Подсказки сгенерированы ИИ и не проверялись человеком — официальными они не являются.

-
H1 Направление ▾

Посмотри на включение диодов относительно источника: при каком поляритете через каждый из них реально может пойти ток? Нарисуй потенциальные уровни в точках, чтобы увидеть направления возможных токов.

H2 Ключевой шаг ▾

Введи уравнения Кирхгофа/Ома для узла C и для ветвей, исключив по мере проверки отключённые диоды; для определения рабочей точки НЛ используй графоаналитический метод — строишь зависимость тока через НЛ от его напряжения, заданную остальной схемой, и ищешь пересечение с ВАХ НЛ.

H3 Почти решение ▾
  1. Предположи, что нижний диод закрыт, отметь, какие ветви при этом отключаются и что из этого следует для тока через и для напряжения на нём.
  2. Запиши баланс токов в узле и выражения токов через резисторы через соответствующие напряжения (оставь их в символической форме с как напряжением на НЛ).
  3. Учти падение напряжения на прямовключённом диоде при необходимости, вырази все второстепенные напряжения через и неизвестные токи ветвей.
  4. Выразите из полученной системы уравнений (получишь линейную зависимость для дальнейшего графического сопоставления с ВАХ НЛ).
