2.1
H1 Направление ▾

Нарисуй мысленно установку: терморезистор и термометр в одном сосуде с водой. Подумай, какие величины тебе нужно зафиксировать в процессе остывания, чтобы получить удобный график зависимости температуры от времени.

H2 Ключевой шаг ▾

Воспользуйся градуировкой терморезистора из Части 1: по измеренному сопротивлению восстанови соответствующую температуру. Для регистрации времени используй секундомер и его память этапов — фиксируй моменты, когда вода достигает заранее выбранных значений температуры.

H3 Почти решение ▾
  1. Подготовь таблицу: в первой колонке запиши ряд фиксированных значений температуры, для которых будешь отмечать времена.
  2. Вторая колонка — внеси соответствующие этим температурам сопротивления, используя кривую градуировки из п.1.1.
  3. Залей воду, дождись, когда она охладится до начальной температуры, запусти секундомер и по мере остывания записывай времена срабатывания памяти секундомера при достижении каждого сопротивления; занеси эти времена в таблицу.
  4. Построй график зависимости температуры воды от времени по полученным точкам и вырази времена τ, соответствующие каждому фиксированному значению температуры, из полученной таблицы.

H1 Направление ▾

Определи, какие доли теплоты пошли: вода отдала часть в окружающую среду и часть передала цилиндру — рассчитай каждую долю в интервалах.

H2 Ключевой шаг ▾

Воспользуйся формулами: для теплоты, отданной водой; с из п.2.2 для отдачи в среду; и для теплоты, полученной цилиндром.

H3 Почти решение ▾

  2. Подсчитай (масса воды — 80 г после погружения) для каждого интервала.
  3. Вычисли используя найденные средние и и среднюю температуру интервала.

Чтобы найти теплоёмкость цилиндра, свяжи накопленную им теплоту с изменением его температуры: теплоёмкость = полученная теплота / приращение температуры цилиндра.

H3 Почти решение ▾

  2. Определи соответствующее изменение температуры цилиндра (начальная — комнатная, конечная — близкая к температуре воды в конце интервала).
