1.1
H1 Направление ▾

Нарисуй систему как одно целое и отдельный брусок, пойми, какие силы действуют на каждый из объектов в установившемся движении (или при постоянном ускорении). Сравни, какие силы внешние, а какие внутренние для системы.

H2 Ключевой шаг ▾

Запиши второй закон Ньютона для всей системы и для одного бруска; используй закон Гука для связи силы пружины с её удлинением. Учти силы трения на каждом бруске.

H3 Почти решение ▾

  2. Запиши второй закон для одного из брусков (того, к которому приложена пружина): его масса умноженная на то же ускорение равна силе пружины минус сила трения на этот брусок.
  3. Вырази силу пружины из уравнения для одного бруска через и параметры системы (массы, трение и т.д.).
