Подсказки

Открывайте по одной — попробуйте продвинуться после каждой, прежде чем открывать следующую.

Подсказки сгенерированы ИИ и не проверялись человеком — официальными они не являются.

1.1
H1 Направление ▾

Нарисуй схему с неизвестным резистором и реостатом, подумай, как измерить ток, не перегружая источник; какие величины ты можешь легко измерить мультиметром?

H2 Ключевой шаг ▾

Запиши закон, связывающий ток и напряжение для омического резистора и используй измерение напряжения на эталонном резисторе для определения тока в цепи.

H3 Почти решение ▾
  1. Собери схему для измерения напряжения на неизвестном резисторе и параллельно включённого эталонного резистора, измерь напряжения и по вычисли ток через неизвестный участок.
  2. Собери таблицу пар для неизвестного резистора, охватив максимально возможный диапазон напряжений.
  3. Построй график и выполни линейную аппроксимацию, найдя коэффициент наклона зависимости.
  4. Вырази сопротивление неизвестного резистора через найденный коэффициент наклона из полученной системы.
1.2
H1 Направление ▾

Нарисуй схему с лампочкой и подумай, как будет меняться её нить накала при увеличении тока; что это значит для сопротивления лампочки?

H2 Ключевой шаг ▾

Учти, что лампочка нелинейна: её сопротивление растёт при нагреве нити, поэтому пользуйся экспериментальной ВАХ; при желании можно попробовать линеаризовать зависимость, например построив против .

H3 Почти решение ▾
  1. Собери схему с лампочкой и эталонным резистором, измерь пары , вычисляя по напряжению на .
  2. Построй экспериментальную ВАХ лампочки и отметь её нелинейный характер (рост сопротивления при нагреве — более слабый рост тока).
  3. При желании построй график и выполни приближение прямой, найдя параметры аппроксимации.
  4. Вырази приближённую зависимость из полученной системы аппроксимации.
1.4
H1 Направление ▾

Подумай, что одинаково у резистора и лампочки при их параллельном соединении; какие величины складываются?

H2 Ключевой шаг ▾

Используй правило для параллельного соединения: суммарный ток равен сумме токов через отдельные ветви, причём для резистора берётся по закону Ома, а для лампочки — по экспериментальной ВАХ.

H3 Почти решение ▾
  1. Возьми набор напряжений и для каждого вычисли по найденному из п.1.1 и возьми из измеренной ВАХ лампочки.
  2. Для каждого просуммируй токи и занеси результаты в таблицу.
  3. Построй рассчитанную ВАХ параллельной пары и экспериментально измерь ВАХ той же пары, нанося точки на тот же график.
  4. Вырази суммарную зависимость из полученной системы и сравни её с точками измерений.
