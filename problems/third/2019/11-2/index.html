Условие

Городская олимпиада (3-й этап) 2019 11 класс № 2

В задаче рассматриваются собственные колебания симметричной цепочки, состоящей из одинаковых шариков, соединенных одинаковыми пружинами. Масса каждого шарика , жесткость каждой пружины , масса пружин пренебрежимо мала. Внешние силы на цепочку не действуют.

Мы будем рассматривать только симметричные продольные колебания. Поэтому достаточно описать движение половины цепочки, полагая при этом, что центральный шарик неподвижен. Для описания движения будем использовать функции - зависимость смещения -того шарика от его положения равновесия.

Собственным колебанием называется такое колебание, при котором все шарики колеблются по гармоническому закону с одной частотой, в одной фазе, но с разными амплитудами. Частоты таких колебаний называются собственными частотами.

Часть 1. Один движущийся шарик.

1.1 Найдите собственную круговую частоту колебаний цепочки, в которой движется только один шарик.

Часть 2. Два движущихся шарика.

Рассмотрим цепочку, в которой движутся два шарика.

2.1 Запишите уравнения, описывающие движения шариков. В качестве единственного параметра этих уравнений используйте частоту , найденную в первой части задачи.

2.2 Определите собственные частоты колебаний шариков и . Найдите при каком отношении амплитуд колебаний каждого шарика их колебания будут проходить с одной частотой.

Часть 3. Длинная цепочка.

Рассмотрим собственные колебания цепочки, состоящей из движущихся шариков.

3.1 Запишите в общем виде уравнения, описывающие движение шарика номер . Укажите какие дополнительные условия следует наложить на крайние шарики и .

3.2 Определите все собственные частоты продольных колебаний данной цепочки. Сколько собственных частот имеет цепочка?

Гуманитарная помощь!
Для решения поставленной задачи следует выполнить следующую последовательность действий:

3.2.1 Представьте решение системы уравнений движения в виде и получите систему уравнений для амплитуд колебаний шариков .

3.2.2 Зависимость амплитуд колебаний от номера шарика может быть записана в виде . Приведите качественные обоснования для поиска решений в таком виде. Получите уравнение для определения в зависимости от частоты колебаний .

3.2.3 Используя уравнение для последнего шарика определите возможные значения параметра , при котором это уравнение выполняется.

3.2.4 Сравнивая результаты, полученные в п.3.2.2 и 3.2.3, получите формулу для собственных частот колебаний.
