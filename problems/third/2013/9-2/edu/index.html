Часть 2.

Напряжения источников одинаковы и равны .

Вольтметр измеряет суммарное падение напряжения по последовательному набору резисторов между его клеммами; представь, какие сопротивления и токи на этом пути.

Запиши напряжения на отдельных резисторах через закон Ома и сложи их вдоль цепи, по которой измеряется вольтметр.

  1. Определи, какие резисторы последовательны между клеммами вольтметра и какие через них текут токи (взятые из пунктов 1.1–1.2).
  2. Запиши выражения для каждого такого резистора.
  3. Сложи эти падения, чтобы получить суммарное напряжение между клеммами вольтметра.
  4. Выразите показание вольтметра из полученной суммы падений напряжения.

2.1 Укажите направления токов через все резисторы и амперметры в этом случае.

Если все источники равны, подумай, как симметрия схемы и равные падения на одинаковых резисторах определяют направления токов.

Используй симметрию и закон Ома : при одинаковых ЭДС и равных сопротивлениях через одинаковые резисторы будут течь одинаковые по модулю токи; применяй также закон сохранения тока в узлах для знаков.

  1. Нарисуй схему и пометь направления токов в очевидно симметричных ветвях по предположению равных падений.
  2. Запиши для каждой ветви соотв. ток как (по модулю).
  3. Применяя узловые уравнения, выясни, какие амперметры будут показывать нулевой ток из-за встречных направлений.
  4. Выразите направления токов через все резисторы и амперметры из полученной системы.

2.2 Каковы показания всех амперметров?

Определи, какие амперметры стоят в ветвях, где токи равны и куда встречные потоки компенсируют друг друга.

Воспользуйся результатом равенства токов в резисторах и законом сохранения тока в узлах, чтобы найти показания каждого амперметра.

  1. Запиши значение тока через каждый резистор по модулю как .
  2. Для каждого амперметра запиши узловое уравнение, учитывая направления токов из пункта 2.1.
  3. Определи, где суммы встречных токов дают ноль, а где остаётся ненулевой поток.
  4. Выразите показания всех амперметров через найденные токи резисторов.

2.3 Какое напряжение показывает вольтметр?

Часть 3.

Полярности двух источников изменили на противоположные (см. рисунок). Напряжения всех источников, по-прежнему, одинаковы по модулю и равны .

Вольтметр фиксирует суммарное падение на том же пути, что и раньше — учти теперь равные падения на одинаковых резисторах.

Сложи напряжения на последовательно расположенных резисторах, используя с найденными из пункта 2.2 токами.

  1. Определи, какие резисторы лежат между клеммами вольтметра и какие через них текут токи (по пунктам 2.1–2.2).
  2. Запиши для каждого такого резистора и подставь найденные значения токов.
  3. Просуммируй эти падения для получения искомого напряжения.
  4. Выразите показание вольтметра из полученной суммы падений напряжения.

3.1 Укажите направления токов через все резисторы и амперметры в этом случае.

Изменённая полярность двух источников приводит к встречным напряжениям в разных ветвях — подумай, где возникнут встречные токи и где суммарный поток будет в каком-либо направлении.

Применяй симметрию схемы, закон Ома для модулей и закон сохранения тока в узлах, чтобы определить направления потоков.

  1. Обозначь знаки ЭДС в каждой ветви согласно новой полярности и выпиши направление предполагаемых токов по модулю как .
  2. Запиши узловые уравнения с учётом направлений и противоположных вкладов от источников.
  3. Определи, при каких амперметрах встречные потоки компенсируются, а где остаётся ненулевой суммарный ток.
  4. Выразите направления токов через все резисторы и амперметры из полученной системы уравнений.

3.2 Каковы показания всех амперметров?

Определи модули токов в резисторах по их падениям напряжения, учтя противоположные направления ЭДС в некоторых ветвях.

Используй для модулей токов в отдельных резисторах и узловые уравнения, чтобы найти показания амперметров (включая удвоенные значения там, где ветви складываются).

  1. Подпиши токи через резисторы по модулю как с учётом знаков из пункта 3.1.
  2. Составь уравнения для амперметров как суммы или разностей токов ветвей в соответствующих узлах.
  3. Реши эти простые алгебраические соотношения, чтобы найти показания каждого амперметра.
  4. Выразите показания всех амперметров из полученной системы уравнений.

3.3 Какое напряжение показывает вольтметр?

Если на последовательном пути между клеммами вольтметра падения напряжений взаимно противоположны, итоговое показание может равняться нулю — проверь это.

Вычисли суммарное напряжение между клеммами как алгебраическую сумму падений , учитывая знаки падений, и воспользуйся результатами пунктов 3.1–3.2.

  1. Определи последовательный набор резисторов между клеммами вольтметра и их направления падений из пункта 3.1.
  2. Запиши выражения с учётом знаков (положительное или отрицательное падение).
  3. Просуммируй эти алгебраические падения, подставив найденные токи из пункта 3.2.
  4. Выразите показание вольтметра из полученной алгебраической суммы падений напряжения.
