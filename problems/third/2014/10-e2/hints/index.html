H1 Направление ▾

Подумай, как меняется лишь масса груза при добавлении кнопок, а что остаётся неизменным для подвеса и для качения по столу; сделай рисунок и отметь, какие величины варьируются.

H2 Ключевой шаг ▾

Исходи из предположения . Для установления показателя степени линейзируй зависимость экспериментальных данных: выбери степенную трансформацию (например, ) так, чтобы зависимость от числа кнопок стала линейной; для подвешенного кольца используй физическую модель физического маятника, для кольца на поверхности руководствуйся чисто экспериментальным графическим анализом.

H3 Почти решение ▾
  1. Собери данные для каждого случая: значения при разных числах кнопок и вычисли удобную преобразованную величину (например, ), которая даст линейную зависимость при предполагаемом виде зависимости.
  2. Построй график преобразованной величины (ось по вертикали) против числа кнопок и проверь, является ли зависимость прямой линией.
  3. Для подвешенного кольца проанализируй, изменяется ли период при добавлении кнопок; если нет — сделай вывод о значении для этого случая.
  4. Для кольца на поверхности, исходя из линейности графика, выразите показатель степени из соотношения между степенным видом зависимости и найденной линейной зависимостью.
