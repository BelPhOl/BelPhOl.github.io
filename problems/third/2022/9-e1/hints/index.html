1.1
H1 Направление ▾

Нарисуй обе схемы с пометкой выводов и подумай, какие резисторы оказываются последовательно или параллельно при измерении между двумя выводами.

H2 Ключевой шаг ▾

Запиши правило для последовательного соединения (сопротивления складываются) и для параллельного соединения (общее сопротивление задаётся суммой обратных величин).

H3 Почти решение ▾
  1. Выбери пару выводов, например 1–2, и отметь, какие элементы между ними оказываются в последовательности или в параллели.
  2. Применяй правило последовательного сложения к тем резисторам, которые идут подряд, и правило параллельного сложения к тем, которые соединены между теми же узлами.
  3. Повтори для всех трёх пар выводов 12, 23 и 31 отдельно для «звезды» и для «треугольника».
  4. Вырази искомые сопротивления между выводами через сопротивления элементов из полученной системы.
1.2
H1 Направление ▾

Подумай, какие измерения нужно сделать, чтобы сравнить теорию и опыт: какие величины будут по теории зависеть от чего и какие нужно записать.

H2 Ключевой шаг ▾

Запиши, какие зависимые и независимые переменные будут у графиков и используй закон электрических соединений для построения теоретических кривых.

H3 Почти решение ▾
  1. Определи, какие сопротивления ты будешь изменять и какие между какими выводами измерять (всего 6 зависимостей).
  2. Запиши план измерений: порядок изменения третьего резистора, число точек, порядок снятия показаний мультиметра.
  3. Обработай данные в виде таблиц для каждой зависимости и подготовь набор точек для построения графиков.
  4. Сравни экспериментальные точки с теоретическими кривыми, вырази выводы о соответствии по полученной системе данных.
1.2.1
H1 Направление ▾

Проверь мультиметр и подумай, какие показания он будет давать при измерении постоянного резистора и при измерении полного сопротивления реостата.

H2 Ключевой шаг ▾

Измерь сопротивление каждого отдельного резистора и полное сопротивление каждого реостата с помощью омметра, учитывая возможное влияние контактов.

H3 Почти решение ▾
  1. Подключи омметр к выводам каждого элемента в стабильных условиях и зафиксируй показание.
  2. Повтори измерение для каждого реостата между крайними выводами (полное сопротивление).
  3. Замерь несколько раз для оценки разброса показаний и вычисли среднее и приближённую погрешность.
  4. Вырази полученные сопротивления и их погрешности из серии измерений.
1.2.3
H1 Направление ▾

Нарисуй в тех же системах координат теоретические кривые, которые следуют из формул, полученных в пункте 1.1, при подставленных значениях фиксированных резисторов.

H2 Ключевой шаг ▾

Подставь в теоретические выражения значения постоянного резистора и фиксированного реостата и построй зависимости теории от переменного сопротивления третьего реостата.

H3 Почти решение ▾
  1. Для каждой из трёх пар выводов выпиши теоретическую зависимость от переменного сопротивления третьего резистора.
  2. Построй на одних и тех же осях экспериментальные точки и теоретические кривые для наглядного сравнения.
  3. Укажи области, где наблюдается расхождение между теорией и опытом и величину этого расхождения.
  4. Вырази теоретические функции и построй графики по ним для сравнения с экспериментальными данными.
1.2.4
H1 Направление ▾

Подумай, какие реальные факторы могут вызвать расхождения: контакты, сопротивление проводов, точность мультиметра, температурная зависимость.

H2 Ключевой шаг ▾

Перечисли возможные источники систематической и случайной погрешности и укажи, как они влияют на измеренные значения по закону сложения сопротивлений.

H3 Почти решение ▾
  1. Оцени вклад контактных и проводниковых сопротивлений в общее значение и сравни с величиной измеряемых сопротивлений.
  2. Проанализируй влияние неточности установки реостата и разброса повторных измерений на точки графика.
  3. Сформулируй способы уменьшения расхождений (коррекция на сопротивление проводов, улучшение контактов, большее число точек).
  4. Вырази величины возможных погрешностей и их влияние на соответствие экспериментальных и теоретических зависимостей.
